# Arduino: armado y carga

## Materiales

- 1 Arduino Nano **clásico ATmega328P**, con cable USB que transfiera datos.
- 1 pulsador normalmente abierto y 1 switch de dos posiciones.
- 2 LEDs comunes y **una resistencia de 330 Ω por LED**.
- Protoboard y cables.

## Prueba sin Processing

Pulsar el botón de D2 debe encender L1 y soltarlo debe apagarlo. Cerrar el switch de D3 debe encender L2 y abrirlo debe apagarlo. Si esto falla, resolver el montaje o la carga antes de revisar Processing.
